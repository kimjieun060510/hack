# MATE

새내기의 하루를 구제해줄 서비스 — 해커톤 디자인 프로토타입

시간표·과제·학과 공지를 한 달력에 모으고, 밥약·과팅·놀기로 사람도 이어주는 새내기용 앱입니다.

## 시뮬레이터에서 실행 (Flutter 앱)

터미널에 아래를 그대로 치면 돼요.

```bash
cd mate
flutter pub get
```

그다음 쓰는 환경에 맞춰 **한 줄만** 더 치면 됩니다.

```bash
# 아이폰 시뮬레이터 (맥)
open -a Simulator
flutter run -d ios

# 안드로이드 에뮬레이터 (에뮬레이터를 먼저 켠 뒤)
flutter run -d android

# 시뮬레이터가 없으면 크롬에서 보기
flutter run -d chrome
```

자세한 설명은 [`mate/README.md`](mate/README.md) 에 있어요. Flutter가 아직 없으면 [설치 가이드](https://docs.flutter.dev/get-started/install)를 먼저 따라가면 됩니다. 설치 확인은 `flutter doctor` 입니다.

## 브라우저에서 바로 보기 (HTML 프로토타입)

`index.html` 을 더블클릭해도 되고, 터미널에서는:

```bash
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열면 됩니다. 설치가 필요 없어요.

## 화면 구성 (Flutter 앱)

| 화면 | 내용 |
|---|---|
| 로그인 · 회원가입 | 학번 로그인, 학생증 인증으로 가입 → **메인화면이 먼저** 떠요 |
| 메인화면 | 밥약 · 과팅/놀기 · 달력 · 내 약속 카드 4개 |
| 밥약 · 놀기 | 맞팔(서로 팔로우)한 친구끼리만 매칭 — 밥약 수락·거절, 랜덤 매칭, 밥약 보내기, 놀기 |
| 과팅 | 팔로우와 상관없이 가입한 모든 학생이 대상 |
| 과팅 / 놀기 | 과팅 찾기·만들기, 놀기(받은 신청 · 놀 친구 구하기), 매너 경고 |
| 달력 · 추천 | 주간·월간 달력, AI 건강 챙기기, 관심 분야 소식 → "달력에 추가" (관심사는 처음 열 때 한 번만 고름) |
| 내 약속 · 내 정보 | 잡힌 약속 모아보기, 성별·정보 연결·로그아웃 |

(HTML 프로토타입 `index.html` 은 예전 구성 그대로예요.)

## 참고

- 화면에 나오는 이름, 일정, 공지는 모두 예시 데이터입니다. 실제 학교 시스템과 연동되어 있지 않습니다.
- 웹 프로토타입은 `index.html` 한 파일에 들어 있습니다. 앱 이름은 `APP_NAME`, 추천 소식은 `OPPS`에서 바꿀 수 있습니다.
- Flutter 앱 코드는 `mate/` 폴더에 있습니다. (`pubspec.yaml` 의 이름과 같습니다.)
