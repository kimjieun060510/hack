# 하루구제

새내기의 하루를 구제해줄 서비스 — 해커톤 디자인 프로토타입

시간표·과제·학과 공지를 한 달력에 모으고, 밥약·과팅·놀기로 사람도 이어주는 새내기용 앱 화면을 만든 프로토타입입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다. 설치나 서버가 필요 없습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 추천 | 관심 분야에 맞는 소식 추천, 누르면 원문으로 이동, "달력에 추가" |
| 달력 | 주간·월간 보기, 일정 종류 필터, 직접 일정 추가, AI 건강 챙기기 |
| 사회생활 | 밥약(익명·한마디), 과팅(3명 팀·매너 경고), 놀기, 푸시·배너 알림 |

## 참고

- 화면에 나오는 이름, 일정, 공지는 모두 예시 데이터입니다. 실제 학교 시스템과 연동되어 있지 않습니다.
- 데이터와 화면 코드는 `index.html` 안에 함께 들어 있습니다. 앱 이름은 `APP_NAME`, 추천 소식은 `OPPS`에서 바꿀 수 있습니다.
